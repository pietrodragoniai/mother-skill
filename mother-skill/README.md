# Mother Skill · Skill per Claude Code

Percorso guidato Starter Zero → Idea → Prodotto. Avvio manuale: `/mother-skill` (skill personale). Installata come plugin: `/mother-skill:mother-skill`.

Il core è `SKILL.md`, con riferimenti on-demand in `references/`, quiz in `data/`, script senza dipendenze aggiuntive in `scripts/`, template di progetto in `templates/` e test in `tests/`.

Il profilo didattico personale (su consenso) e il Second Brain di progetto vanno tenuti separati. Il limite del contesto al 70% è una regola operativa prudenziale, non un limite tecnico. «75% token risparmiati» è un benchmark da verificare.
