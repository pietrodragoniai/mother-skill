# Glossario essenziale — in parole semplici

| Termine | Significato e utilità |
|---|---|
| Repository (repo) | Cartella di progetto tracciata da Git: contiene codice e storia delle modifiche. |
| Git | Sistema di versionamento locale, registra cambiamenti e permette di confrontare/ripristinare versioni. |
| GitHub | Servizio per ospitare repo, collaborare, gestire PR e CI; diverso da Git. |
| Branch | Linea di lavoro separata; una feature non interrompe il ramo principale. |
| Commit | Snapshot commentato e selezionato del lavoro in Git. Non è un backup remoto finché non fai push. |
| Push / Pull | Inviare commit al remoto / recuperare commit remoti. |
| Pull Request (PR) | Proposta verificabile di fondere un branch in un altro, con diff e controlli. |
| Merge | Unire modifiche da un branch a un altro. |
| CI/CD | Test/build automatici e pipeline di distribuzione; un check verde non garantisce assenza di bug. |
| Deploy | Pubblicare una versione in un ambiente. Preview/staging e production sono diversi. |
| Frontend | Codice dell'interfaccia che l'utente vede. |
| Backend | Logica server, API, permessi e accesso ai dati. |
| API | Interfaccia con cui programmi si parlano secondo regole. |
| Node.js | Runtime che esegue JavaScript fuori dal browser; npm è il gestore pacchetti. |
| JavaScript / TypeScript | Linguaggio web / sua variante con sistema di tipi statici compilata in JS. |
| JSON | Formato testuale strutturato per dati e configurazioni, non un database. |
| SQL | Linguaggio usato per interrogare e modificare database relazionali. |
| PostgreSQL (Postgres) | Sistema database relazionale che usa SQL. SQL e Postgres non sono sinonimi. |
| Supabase | Piattaforma backend basata, tra l'altro, su PostgreSQL, con auth, storage e API. |
| Vercel | Piattaforma per distribuzione e hosting, soprattutto di app web. Non sostituisce automaticamente il database. |
| Firebase | Servizi backend/hosting di Google; Firestore è documentale, non SQL/Postgres. |
| ORM | Strato software che aiuta a interagire con il DB tramite oggetti/tipi; non elimina migrazioni e SQL. |
| Migration | Modifica versionata dello schema del database, da provare e rendere recuperabile. |
| Auth / autorizzazione | Verifica chi sei / che cosa puoi fare: aspetti diversi. |
| Secret / .env | Credenziale riservata / possibile file locale di configurazione; non pubblicare chiavi nel repo. |
| Wiki | Documentazione stabile sul perché e come funziona il progetto. |
| Second brain | Sistema organizzato di wiki, decisioni e handoff che consente di riprendere con poco contesto. |
| Handoff | Sintesi operativa per riprendere la sessione: stato, evidenze, prossimi passi, blocchi. |
| Changelog / SemVer | Cronologia rilasci / convenzione major.minor.patch, se il progetto la adotta. |
| GSAP | Libreria di animazioni JavaScript per web e motion. |
| HyperFrames | Framework che rende video MP4 a partire da HTML/CSS/JS e scene temporizzate. |
| Remotion | Framework per video programmatici usando React. |
| Blender | Software 3D per modelli, rig, animazione e rendering. |
