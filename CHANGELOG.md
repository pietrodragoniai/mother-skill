# Changelog

## [1.0.0] — 2026-10-09 — Mother Skill, prima beta

- Rebranding completo di Opus Inline Studio 4.3 in **Mother Skill**; comando `/mother-skill`.
- Manifesto irriverente, README, FAQ, guida HTML, kit lancio e documentazione GitHub aggiornati.
- Starter Zero Mac/Windows mantiene verifica CLI/login e scelta cartella, senza reinstallare Claude Code presente.
- Quiz adattivo, Grill Me, task, anteprime A/B/C dove utili, sviluppo Opus inline, review di progetto a fine release, Second Brain, limiti contesto 60/70% e gate CI/deploy.
- Plugin con manifest e marketplace locale/GitHub; mantiene anche installazione standalone della skill.
- Test automatici estesi per brand, metadata e pacchetto.

## Provenienza

Derivata da Opus Inline Studio 4.3. La vecchia skill può coesistere nella cartella personale; per evitare confusione va eventualmente archiviata **solo su scelta esplicita dell'utente**. Nessuna cronologia Git pregressa viene dichiarata o inventata.
