Ci pensa mamma.

Your mom, but for coding. Ti accompagno anche se non sai ancora aprire una cartella in Claude Code.

Non ti preparo la merenda. Ti preparo la pull request. Nessun programma speciale: sei già nel browser. Funziona anche senza Internet, tranne i link alle guide ufficiali.

Prima di iniziare: estrai tutto lo ZIP in una cartella. Non aprire gli installer direttamente dall'anteprima dello ZIP. Questa pagina e gli installer devono rimanere nella stessa cartella estratta.

Verifica o installa Claude Code

Apri la guida ufficiale di Claude Code e segui la procedura indicata per il tuo sistema operativo. Non installare da siti sconosciuti.

Se sai aprire il terminale, prova il comando qui sotto. Se Claude Code è già installato, non serve reinstallarlo.

Mac: apri Terminale da Applicazioni → Utility.

Windows: apri PowerShell dal menu Start.

claude --version
claude auth status

Se il primo comando non è riconosciuto, segui la guida ufficiale; se il login non è verificato, completa l'accesso nella procedura ufficiale. Non condividere password o chiavi API.

4. Se qualcosa non funziona

Non so cos'è una cartella di progetto

È una normale cartella sul computer in cui salverai i file del progetto. La skill lavora su quella cartella, senza dover aprire tutto il computer. L'avviatore ne propone una se non ne hai.

Il mio computer non apre i file .md

Non devi aprirli: questa pagina HTML è la guida per principianti. I file Markdown sono documentazione tecnica. Se vuoi leggerli comunque, puoi usare Blocco note su Windows, TextEdit su Mac oppure un editor di testo.

Ho già Claude, perché dovrei installare qualcosa?

Claude Code e Mother Skill sono cose diverse. Se Claude Code funziona, l'installer serve soltanto ad aggiungere questa skill. Non effettua logout o reinstallazioni.

Claude non trova il comando /mother-skill

Controlla di aver eseguito l'installer della skill e aperto una nuova sessione Code. La chat Claude ordinaria potrebbe non vedere la cartella locale. Se usi Desktop Code, le skill personali possono dipendere dal supporto della tua versione.

Mac/Windows blocca l'installer

Non disattivare controlli di sicurezza. Verifica che il pacchetto provenga dalla persona o repository attendibile. In alternativa l'installazione manuale consiste nel copiare la cartella mother-skill dentro ~/.claude/skills/ (Mac) o %USERPROFILE%\.claude\skills\ (Windows), senza cancellare altre cartelle.

Serve GitHub oppure un database subito?

No. Per iniziare basta una cartella di progetto e Claude Code funzionante. La skill introdurrà GitHub, database, hosting e altri strumenti quando necessari, prima spiegando a cosa servono.
