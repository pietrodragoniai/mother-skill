# Contribuire a Mother Skill

Grazie per aiutare mamma a crescere. 😄

- Apri una issue separata per ogni bug o proposta. Specifica macOS/Windows, versione Claude Code, ramo di onboarding e passaggi per riprodurre.
- Non caricare screenshot con token, credenziali, indirizzi o dati sensibili.
- Proponi PR piccole e testabili. Mantieni **Starter Zero** comprensibile a chi non programma.
- Non aggiungere dipendenze, account o servizi a pagamento come requisito obbligatorio.
- Non cambiare i gate di sicurezza o inventare misure di risparmio token.

Test locali: `cd mother-skill && python -m unittest discover -s tests -v`, poi `python -m unittest discover -s benchmarks -v` dalla radice.
